# Brand files

Source art for the atlas, kept here so a logo change is a commit and not a lost download.

| File | Where it goes |
|---|---|
| `avatar-1024.png` | GitHub account or organisation avatar (GitHub crops it to a circle) |
| `social-preview-1280x640.png` | GitHub repository social preview: Settings → General → Social preview |
| `mark.png` | the mark at full resolution — the head, no padding, for re-cropping |
| `mascot.png` | the mascot at full resolution — the sitting raccoon, no padding |

What the site itself serves is built from these and lives elsewhere: `src/assets/atlas-mark.png`
(header logo), `public/favicon.png`, `public/apple-touch-icon.png`, `public/og.png`.

Palette: `#2f6f4f` deep green, `#a7d7bd` mint, `#f8faf5` paper, `#1e2b24` ink.
