## 1. Collect the input

Ask for these and wait:

1. **What the project does**, in the author's own words, and what a person can do inside it.
2. **The language the audience searches in.** Not the interface language. It decides which results
   pages you check in step 4 and which heading set the drafts use in step 7.
3. **A Search Console export, if there is one** — Performance report, Export, the `Queries` table, as
   CSV or as the downloaded ZIP. Optional. Say plainly that without it steps 2 and 3 below run on
   guesses, and the plan is weaker.

If an export is uploaded, read its header and the row count, and name the columns you are using before
going on. A Search Console UI export stops at 1,000 rows; if the file has exactly 1,000, say the tail is
cut off.

**Sort by impressions, not by clicks.** A query with impressions and no clicks is demand you already
touch and lose — the cheapest cluster in the file.
