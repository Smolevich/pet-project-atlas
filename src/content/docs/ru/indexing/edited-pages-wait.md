## Что решаем

Вы переписали title или первый экран страницы. Через неделю Search Console не показывает никакой разницы, и вы готовы записать правку в бесполезные.

У меня правка в таких случаях обычно просто не доходила до поиска. Google и ИИ-краулеры держали старую копию, потому что за страницей ещё не возвращались.

## Шаги

1. **Сначала дата последнего обхода, потом метрики.** URL Inspection — строка поиска сверху на любом экране Search Console — показывает у адреса «Last crawl». В API то же поле приходит как `lastCrawlTime`. Если дата раньше деплоя, все числа страницы описывают старую версию.

   ```bash
   curl -s -X POST \
     -H "Authorization: Bearer $(gcloud auth application-default print-access-token)" \
     -H "Content-Type: application/json" \
     https://searchconsole.googleapis.com/v1/urlInspection/index:inspect \
     -d '{"inspectionUrl":"https://example.com/page","siteUrl":"https://example.com/"}' \
     | jq '.inspectionResult.indexStatusResult | {coverageState, lastCrawlTime}'
   ```

2. **Найти краулер в своём access-логе, по пути страницы.** Дата из Inspection — только про Google. Ассистенты присылают своих агентов, и видно их только в логе.

   ```bash
   zcat -f /var/log/nginx/example.access.log* \
     | grep 'GET /edited-page' | grep -c 'OAI-SearchBot'
   ```

3. **Считать показы только после даты обхода.** Всё, что раньше, — это старый title. На трёх моих отредактированных страницах это срезало 169 показов до 64 вместе с днём обхода и до 19 строго после него.
4. **Ждать, что новые страницы сдвинутся первыми.** В тот же день я выложил 8 новых URL. Googlebot забрал 3 из них той же ночью и 7 из 8 за два дня, а показы к третьему дню были у 6. Отредактированные страницы лежали рядом, в том же sitemap.

## Что не сработало

- **Оценивать смену title по недельному окну.** Из 3 страниц с новыми title Googlebot переобошёл 2, на первый и третий день. Третью он обошёл утром, за несколько часов до моего деплоя, и больше за неделю не приходил.
- **Ждать, что ассистент заметит переписанную страницу.** Я переделал лендинг под ответы ИИ. OAI-SearchBot, краулер поиска ChatGPT, за семь дней не запросил его ни разу.
- **Верить одному ответу Inspection.** Статус нового URL прыгал между «URL is unknown to Google», «Discovered» и «indexed» день ото дня. Смысл есть только у последнего.
- **Читать заходы Яндекса и Bing как интерес.** Мой деплой пингует IndexNow — общую точку, через которую Bing и Яндекс узнают об изменённых URL, — всем sitemap. Их заходы в ту неделю были ответом на мой пинг, и я их не считал.

## Проверить

Для каждой изменённой страницы запишите три даты: деплой, последний обход из Inspection и первый заход краулера в логе после деплоя. Если обход не позже деплоя, страница в поиске всё ещё старая.

У меня на седьмой день было так.

| Страница | Правка | Переобход Googlebot | Показы после |
|---|---|---|---|
| главная | title и description | день 1 | считаются с дня 1 |
| лендинг на русском | title и description | день 3 | данных за один день |
| статья-сравнение | description | не переобходил | нет |

В общем, дайте отредактированной странице три недели, прежде чем её судить. Новая страница отвечает за несколько дней, поэтому недельный тест работает только на новых.
