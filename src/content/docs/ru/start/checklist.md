## Что решаем

Тот же маршрут, что на [начать здесь](/ru/start/), только без причин. Там каждый шаг объясняется, здесь — галочки, для скриншота или вкладки, которая висит открытой.

Работать сверху вниз. Ничто отсюда не отменяется тем, что стоит ниже, — только поэтому порядок и важен.

Если от строки хочется спросить «зачем», ответ на странице по ссылке. Список я собрал из того, что считал давно сделанным.

## Шаги

- [ ] Собрать формулировки, которыми говорят люди, их же словами, из поддержки и отзывов — [слова](/ru/demand/how-people-search/)
- [ ] Проверить их в Yandex Wordstat и в Google, с операторами и с подсказками в обоих. Без операторов вернётся итог по категории, а не спрос на вашу фразу — [слова](/ru/demand/how-people-search/)
- [ ] Поискать внутри платформы, где живёт продукт, с аккаунта, который его не трогал — [слова](/ru/demand/how-people-search/)
- [ ] Прочитать ноль по самой очевидной своей фразе как находку, а не как сбой. Либо этой задачи нет ни у кого, либо слово придумали вы — [слова](/ru/demand/how-people-search/)
- [ ] Назвать платного конкурента, посчитать рекламу на запросе, записать бесплатный путь. На аудиторию, которая не тратит, второй раз не ставят — [платят ли](/ru/demand/will-they-pay/)
- [ ] Запросить страницу через `curl -sL` снаружи и без кук, найти в ответе свой текст. Чего нет в ответе, того не видит и crawler — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Прочитать `robots.txt`, потом найти `noindex` в теге и в заголовке. Он выбрасывает страницу из индекса намеренно, а заголовок в браузере не виден — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Направить каждый canonical на свою же страницу, варианты URL свести редиректами к одной форме. Canonical — тег, который называет настоящий URL страницы — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Подтвердить domain property в Search Console, отправить sitemap и импортировать ресурс в Bing. URL-prefix покрывает только ту форму, которую вы вписали — [отдать](/ru/indexing/submit-and-verify/)
- [ ] Отдавать `User-agent: *` и `Allow: /`, а имя агента писать только чтобы закрыть. Поимённый список разрешений протухает при каждом переименовании у вендора — [crawler](/ru/geo/llms-txt-and-crawlers/)
- [ ] Разметить исходящие ссылки по фиксированному значению на площадку и сохранять источник при первом контакте. Приход без метки не разложить по источникам уже никогда — [атрибуция](/ru/analytics/attribution/)
- [ ] Назвать одно действие, которое считается активацией. Активация — то действие, после которого понятно, что продукт сработал — [метрики](/ru/analytics/what-to-measure/)
- [ ] Дать каждому кластеру ровно один URL, в таблице, которую вы ведёте. Кластер — набор формулировок, которым нужна одна страница — [кластеры](/ru/content/keyword-clusters/)
- [ ] Написать первую страницу в форме из четырёх блоков, с ответом в начале. Блоки: задача, шаги, что не сработало, как проверить — [форма страницы](/ru/content/page-templates/)
- [ ] Добавить JSON-LD — машиночитаемые факты о странице — с `sameAs` на ваши профили и карточки. Для Knowledge Graph у Google это задокументировано, для цитирования у LLM — не измерено — [цитируемость](/ru/geo/citable-pages/)
- [ ] Публиковать `llms.txt` только при документации для разработчиков и только с существующими страницами. Мой лог за 16 дней записал 0 обращений от AI-агентов — [crawler](/ru/geo/llms-txt-and-crawlers/)
- [ ] Вынести функцию продукта в имя внутри платформы, в алфавите аудитории. Поиск платформы ищет по имени, а не по описанию — [платформа](/ru/distribution/in-platform-visibility/)
- [ ] Один раз собрать карточку, потом подавать небольшими партиями с размеченными ссылками — [каталоги](/ru/distribution/catalogs/)
- [ ] Дописывать недельный срез в файл, в один и тот же день недели. Число, которое не с чем сравнить месяц спустя, бесполезно — [метрики](/ru/analytics/what-to-measure/)
- [ ] Писать стоимость действия в строку события, потом назвать безубыточность целым числом платящих. Пустая колонка молча роняет любой отчёт на расчётные тарифы — [стоимость](/ru/money/unit-economics/)

## Что не сработало

- **Ставить галочку по памяти**. Каждый пункт здесь — то, что я считал уже сделанным. Половина сделана не была, а проверка занимала минуту.
- **Начинать с проверок индексации**. Этот список раньше с них и начинался, а начинать с них — значит считать, что спрос уже есть. Всё, что ниже первого блока, нацелено на слова, которые кто-то должен набирать.
- **Начинать с середины, с интересного**. Контент и каталоги — приятная половина работы. И то и другое уходит впустую, пока страницы несут заголовок, который их выбрасывает.
- **Отметить пункт про метки, когда метку некуда класть**. Ссылки ушли размеченными, параметр приходил, а колонки под него не было. Галочка стояла честно, данных не было.
- **Считать это списком, который закрывают один раз**. Статус в каталогах, правила на edge и доступ для crawler — это состояние. Оно меняется молча, поэтому верхнюю половину стоит перепроверять раз в квартал.
- **Держать пункт, которому противоречила собственная практика сайта**. Список требовал разрешать агентов поимённо, а `atlas.smolevich.com` всё это время отдавал голый wildcard. Когда совет и файл автора расходятся, честен файл.
- **Требовать `llms.txt` после замера, что его никто не забирает**. Пункт стоял здесь ровно столько же, сколько существовал замер на соседней странице. Чек-лист, переживший собственные доказательства, — привычка, а не порядок работы.

## Проверить

- У каждой поставленной галочки есть артефакт: вывод команды, строка в отчёте, строка в базе. Память артефактом не считается.
- От пунктов про спрос остаётся файл формулировок и названный конкурент. Если чего-то из этого нет, все пункты ниже нацелены в пустоту.
- Пункты про метки проверяются так: зарегистрироваться по своей же ссылке и прочитать сохранённое значение.
- В таблице кластеров столько строк, сколько под них написано страниц, и каждый URL в ней открывается.
- Через квартал перепроверить проверки доступа из начала списка. Хотя бы одна из них к тому времени успеет измениться.
