## Что решаем

Тот же маршрут, что на [начать здесь](/ru/start/), только без причин. Там каждый шаг объясняется. Здесь — галочки, для скриншота или для вкладки, которая висит открытой.

Работать сверху вниз. Ничто отсюда не отменяется тем, что стоит ниже. Только поэтому порядок и важен.

Если от строки хочется спросить «зачем», ответ на странице по ссылке. Список я собрал из того, что считал давно сделанным.

## Шаги

- [ ] Собрать формулировки, которыми говорят люди, их же словами, из поддержки и отзывов — [слова](/ru/demand/how-people-search/)
- [ ] Проверить их в Yandex Wordstat и в Google, с операторами. Прочитать подсказки в обоих движках. Без операторов вернётся итог по категории, а не спрос на вашу фразу — [слова](/ru/demand/how-people-search/)
- [ ] Поискать внутри платформы, где живёт продукт, с аккаунта, который его не трогал — [слова](/ru/demand/how-people-search/)
- [ ] Прочитать ноль по самой очевидной своей фразе как находку, а не как сбой. Либо этой задачи нет ни у кого, либо слово придумали вы — [слова](/ru/demand/how-people-search/)
- [ ] Назвать платного конкурента. Посчитать рекламу на запросе и записать бесплатный путь — [платят ли](/ru/demand/will-they-pay/)
- [ ] Запросить страницу через `curl -sL` снаружи и без кук. Найти в ответе свой текст — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Прочитать `robots.txt`, потом найти `noindex` в теге и в заголовке. Заголовок в браузере не виден — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Направить каждый canonical на свою же страницу. Варианты URL свести редиректами к одной форме. Canonical — тег, который называет настоящий URL страницы — [блокеры](/ru/indexing/why-google-does-not-see-you/)
- [ ] Подтвердить domain property в Search Console и отправить sitemap. Импортировать этот же ресурс в Bing. URL-prefix покрывает только ту форму, которую вы вписали — [отдать](/ru/indexing/submit-and-verify/)
- [ ] Отдавать `User-agent: *` и `Allow: /`, а имя агента писать только чтобы закрыть — [crawler](/ru/geo/llms-txt-and-crawlers/)
- [ ] Разметить исходящие ссылки, по одному значению на площадку. Сохранять источник при первом контакте — [атрибуция](/ru/analytics/attribution/)
- [ ] Назвать одно действие, которое считается активацией. Активация — то действие, после которого понятно, что продукт сработал — [метрики](/ru/analytics/what-to-measure/)
- [ ] Класть в строку события кто, что, когда, источник, стоимость, клиент и итог. Стоимость и источник пишутся только в момент вставки — [строка события](/ru/analytics/product-metrics/)
- [ ] Дать каждому кластеру ровно один URL, в таблице, которую вы ведёте. Кластер — набор формулировок, которым нужна одна страница — [кластеры](/ru/content/keyword-clusters/)
- [ ] Написать первую страницу в форме из четырёх блоков, с ответом в начале. Блоки: задача, шаги, что не сработало, как проверить — [форма страницы](/ru/content/page-templates/)
- [ ] Добавить JSON-LD с `sameAs` на ваши профили и карточки. JSON-LD — блок машиночитаемых фактов о странице. Для Knowledge Graph у Google это задокументировано. Для цитирования у LLM это никто не измерял — [цитируемость](/ru/geo/citable-pages/)
- [ ] Публиковать `llms.txt` только при документации для разработчиков. Перечислять в нём только существующие страницы. Мой лог за 16 дней записал 0 обращений от AI-агентов — [crawler](/ru/geo/llms-txt-and-crawlers/)
- [ ] Вынести функцию продукта в имя внутри платформы, в алфавите аудитории. Поиск платформы ищет по имени, а не по описанию — [платформа](/ru/distribution/in-platform-visibility/)
- [ ] Один раз собрать карточку, потом подавать небольшими партиями с размеченными ссылками — [каталоги](/ru/distribution/catalogs/)
- [ ] Отвечать на вопросы там, где пишутся подборки, и говорить, что продукт ваш. Никогда не выпрашивать upvote — [сообщества](/ru/distribution/communities/)
- [ ] Дописывать недельный срез в файл, в один и тот же день недели — [метрики](/ru/analytics/what-to-measure/)
- [ ] Писать стоимость действия в строку события. Назвать безубыточность целым числом платящих. У меня такой колонки не было вовсе, и стоимость я добирал джойном к тарифам — [стоимость](/ru/money/unit-economics/)
- [ ] Назвать цену, поставить стену после первого настоящего результата и попросить денег у одного человека — [первый платящий](/ru/money/first-payer/)

## Что не сработало

- **Ставить галочку по памяти**. Каждый пункт здесь — то, что я считал уже сделанным. Половина сделана не была. Каждая проверка занимала минуту.
- **Начинать с проверок индексации**. Этот список раньше с них и начинался. Начать с них — значит молча считать, что спрос уже есть. Всё, что ниже первого блока, нацелено на слова, которые кто-то должен набирать.
- **Начинать с середины, с интересного**. Контент и каталоги — приятная половина работы. И то и другое уходит впустую, пока страницы несут заголовок, который выбрасывает их из индекса.
- **Отметить пункт про метки, когда метку некуда класть**. Ссылки у меня ушли размеченными, параметр приходил с каждым визитом. Колонки под него не существовало. Галочку я поставил честно, а данных всё равно нет.
- **Считать это списком, который закрывают один раз**. Статус в каталогах, правила на edge и доступ для crawler — это состояние. Состояние меняется молча. Верхнюю половину я перепроверяю раз в квартал.
- **Держать пункт, которому противоречила собственная практика сайта**. Список требовал разрешать агентов поимённо. `atlas.smolevich.com` всё это время отдавал голый wildcard. Прав был файл, а не список.
- **Требовать `llms.txt` после замера, что его никто не забирает**. Замер лежал на соседней странице. Пункт стоял здесь ровно столько же. И я продолжал его отмечать.

## Проверить

- За каждой поставленной галочкой стоит артефакт: вывод команды, строка в отчёте, строка в базе. Память артефактом не считается.
- От пунктов про спрос остаётся файл формулировок и названный конкурент. Если чего-то из этого нет, всё отмеченное ниже нацелено в пустоту.
- Пункты про метки проверьте так: зарегистрируйтесь по своей же ссылке и прочитайте сохранённое значение.
- В таблице кластеров столько строк, сколько под них написано страниц. Каждый URL в ней открывается.
- Через квартал перепроверить проверки доступа из начала списка. Хотя бы одна из них к тому времени успеет измениться.
