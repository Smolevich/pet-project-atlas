## Что решаем

Атлас не поставляет свой аудит. Хорошие инструменты уже есть, а переписывать их — плодить худшую копию, которую никто не поддержит.

Не хватает карты: какой инструмент отвечает на какой вопрос и в каком порядке их запускать.

Каждая сторонняя строка ниже — пакет, установленный на моей машине, кроме одного платного сервиса. Лицензия взята из исходного репозитория, а для сервиса — из того, что покупается за деньги.

## Шаги

| Инструмент | Что делает | Когда браться | Откуда | Лицензия |
|---|---|---|---|---|
| `seo-audit` | Технический SEO-аудит: обход, индексация, on-page, скорость страницы | Поиск по сайту не отдаёт ничего или страница выпала из индекса | Skill, `coreyhaines31/marketingskills` | MIT |
| `geo` | Точка входа над GEO-скиллами, отправляет URL в нужный | Хочется одной командой, а какая проверка нужна — ещё непонятно | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-audit` | Полный GEO-аудит параллельными субагентами, один сводный балл | Замер до того, как вы что-то меняли, и он же через месяц | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-citability` | Оценивает куски текста на то, насколько вероятно модель их процитирует | Страницы написаны, а ассистенты по-прежнему цитируют не вас | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-crawlers` | Читает `robots.txt`, мета-теги и заголовки в карту доступа по агентам | Перед любой работой над цитируемостью и после любой правки на edge | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-llmstxt` | Проверяет существующий `llms.txt` или собирает черновик по структуре сайта | Вы публикуете файл или ссылки в нём протухли | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-schema` | Находит и валидирует JSON-LD, генерирует недостающие блоки | Разметки сущности нет или редизайн мог её сломать | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| `geo-report` | Собирает результаты аудита в один документ для читателя | Действовать по находкам придётся кому-то ещё | Skill, `zubair-trabzada/geo-seo-claude` | MIT |
| Playwright MCP | Водит настоящий браузер в вашем профиле, с вашими живыми сессиями | Search Console, консоль магазина, любая панель без пригодного API | npm `@playwright/mcp`, `microsoft/playwright-mcp` | Apache-2.0 |
| `gws` | Одна авторизованная командная строка над API Google Workspace | Держать недельный ряд в Sheet, вытащить экспорт из Drive | npm `@googleworkspace/cli`, `googleworkspace/cli` | Apache-2.0 |
| Semrush | Domain Overview по данным Google: позиции, backlinks, Authority Score, панель AI Search | Нужны позиции и ссылки по домену, который изнутри не измерить | Hosted service, `semrush.com` | Paid subscription, not a skill |
| `/atlas:start` | Проводит проект по маршруту, вызывая скиллы аудита в нужных точках | Есть живой URL и нет понимания, какую проблему чинить первой | This repo, `plugin/` | MIT |
| `/atlas:content-plan` | Превращает описание проекта и выгрузку запросов в кластеры, по странице на каждый | Нужно понять, что писать и в каком порядке | This repo, `plugin/` | MIT |
| `/atlas:report` | Недельный срез Search Console и Analytics: что сдвинулось, что делать | Недельный снимок, когда ресурс подтверждён и есть токен | This repo, `plugin/` | MIT |
| `/atlas:voice` | Приводит черновик к `STYLE.md` до того, как его увидит линтер | Перед тем как открывать pull request в этот репозиторий | This repo, `plugin/` | MIT |

1. **Ставить сторонние скиллы из их репозиториев** — CLI скиллов принимает владельца и имя репозитория.

   ```bash
   npx skills add coreyhaines31/marketingskills
   npx skills add zubair-trabzada/geo-seo-claude
   ```

2. **Читать лицензию в исходном репозитории, а не в папке скилла** — в установленном `SKILL.md` строки о лицензии нет.
   Lock-файл `~/.agents/.skill-lock.json` хранит репозиторий, откуда пришёл каждый скилл. С этим именем и идти за лицензией.
3. **Запускать `seo-audit` первым, когда в индексе пусто** — он проходит забор, блокировку и canonical за один заход.
   Это быстрее, чем проверять семь вещей руками, и на сломанном он падает громко.
4. **Запускать `geo-crawlers` раньше `geo-citability`** — доступ решает, прочитают ли текст вообще.
   Заблокированный агент не процитирует страницу, какой бы хорошей она ни была.
5. **`geo-audit` — для замера, точечный скилл — для починки** — сводный балл это точка отсчёта.
   Перезапустите тот же аудит после работы. Дельта — единственная часть балла, которая что-то значит.
6. **Браться за Playwright MCP только там, где API нет** — панель за логином, консоль без экспорта.
   Водить свой профиль, тогда авторизованные сессии уже есть. Чистый профиль показывает форму входа.
7. **Проверять `gws --help` на нужный сервис** — список печатает ваша же установленная сборка.
   Она покрывает Workspace. Search Console и Analytics в ней нет.
8. **Четыре команды `/atlas:` подключаются через плагин в `plugin/`** — добавить этот репозиторий как marketplace, потом поставить `atlas`.
   Команды задают маршрут и порядок. Сам аудит остаётся за сторонними скиллами выше, поэтому плагин и тонкий.

## Что не сработало

- **Тянуть числа Search Console через `gws`**. В справке есть форма `<api>:<version>` для неперечисленных API. Я попробовал `searchconsole:v1` и `analyticsdata:v1beta`, оба вернулись неизвестными сервисами. Эти числа берутся из их собственных API или руками из консоли.
- **Искать лицензию внутри установленного скилла**. В папках под `~/.claude/skills/` лежат `SKILL.md` и скрипты. Ни лицензии, ни автора, ни имени репозитория. Происхождение выживает только в lock-файле, который написал установщик.
- **Считать балл аудита работой**. Сводное число двигается от чего угодно. Поведение меняла одна строка отчёта: агент, получивший 403, кусок текста, который никто не мог процитировать.
- **Гонять проверки цитируемости, пока crawler заблокирован**. Отчёт бодро оценивал мою прозу. Страницу неделями не забирал ни один агент, так что балл был про документ, который никто не скачивал.
- **Водить чистый профиль браузера по панелям за логином**. Каждый запуск начинался с экрана входа. До панели доезжает только профиль с живой сессией.
- **Верить, что этот список стабилен**. У сторонних скиллов между обновлениями меняются владельцы, лицензии и поведение. Проверяйте репозиторий в день установки и ещё раз перед тем, как копировать что-то к себе.

## Проверить

- `cat ~/.agents/.skill-lock.json` и прочитать `sourceUrl` каждого установленного скилла. Это и есть репозиторий, чья лицензия действует.
- Открыть этот репозиторий и прочитать файл `LICENSE`. Файла нет — условия неизвестны, а неизвестны значит не распространять.
- Запустить `gws --help` и найти свой сервис в напечатанном списке. Отсутствующий сервис отсутствует, что бы ни писали в гайде.
- Запустить `seo-audit` по странице, которую вы уже починили. Если отчёт всё ещё её ругает, починка не доехала до прода.
- Запустить `geo-crawlers` из сети, которая не ваша. Карта доступа, снятая изнутри вашей сети, прячет правила на edge.
